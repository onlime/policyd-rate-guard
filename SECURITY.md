# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/onlime/policyd-rate-guard/security/advisories/new) or by email to info@onlime.ch. We'll confirm within a few working days and keep you informed until a fix is released.

Relevant for this project are in particular ways to send mail past the rate limit, to change other senders' counters or quotas, to get the daemon to answer with its `FAIL_ACTION`, and leaks of configuration secrets or personal data (logs, error reports, webhooks).
